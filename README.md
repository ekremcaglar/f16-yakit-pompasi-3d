# F-16 Yakıt Boost Pompası — 3B Etkileşimli Eğitim Simülasyonu

Canlı: https://ekremcaglar.github.io/f16-yakit-pompasi-3d/

Elektrikli santrifüj yakıt boost pompasının (F-16 rezervuar tankı) 3B, parçalara ayrılabilir (teardown) ve etkileşimli eğitim modeli.
three.js ile prosedürel olarak modellenmiştir; derleme adımı gerekmez (statik site).

**Uyarı:** Eğitim amaçlıdır. Resmî T.O./CMM verisi değildir. Kaynakta bulunmayan değerler (devir, akım, sıcaklık, arıza tepkileri) temsilidir.
Nominal değerler ve sistem açıklamaları uygulamadaki "Kaynaklar" sekmesinde listelenen açık kaynaklara dayanır (Eaton F-16 broşürü, Derco/Eaton FFP föyü, Falcon BMS dash-1, Eaton pompa veri sayfaları, NASA NTRS, ARC CP-1128, ASME).

URL parametreleri: `?power=1&explode=1&cut=1&xray=1&labels=1&fault=cav|clog|lowv|phase|dry&select=impeller`
